# Pixel Rotated Ellipse Renderer
A simple JavaScript implementation for rendering general ellipses pixel-by-pixel. Designed for graphics enthusiasts, creative coders, or anyone curious about low-level rasterization techniques.

## Features

- **General ellipse support:** Draws rotated and non-axis-aligned aka General ellipses
- **Pixel-by-pixel rendering:** Pixel quality rasterization
- **Educational:** Ideal for learning 2D graphics and ellipse math
